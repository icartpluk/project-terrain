# Simulation and validation plan

## Phase 1 — requirements and hazard analysis
Define representative *inert* underground scenarios, operator roles, system boundaries, safety cases, and measurable pass/fail criteria.

## Phase 2 — digital simulation
Model rubble-like obstacles, poor lighting, localization uncertainty, intermittent communications, robot stability, and generic tool use. Use no nuclear-material access or recovery procedures.

## Phase 3 — physical mock-up
Test in a controlled training environment using harmless surrogate objects, independent emergency stops, and supervised operators.

## Phase 4 — independent review
Compare humanoid and purpose-built alternatives; assess safety, reliability, cyber resilience, and practical feasibility. Record failures as well as successes.

## Phase 5 — decision gate
Only after independent validation should specialists determine whether further research is warranted. Real nuclear applications require separate authorization and expert-led safety programs.

## Mars technology transfer
Evaluate mapping, excavation support, teleoperation latency tolerance, and infrastructure preparation in a separate non-nuclear test environment.
