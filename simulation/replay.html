    Communication and stopping delays
    

      
      
      
    

    
Zero means the original instant stop. E-stop bypasses communication delay. During a delay the robot follows its existing route, up to one cell per tick; it waits at G if it arrives before the stop. This is an idealized software model, not physical braking.

    How the demo works
    
The robot follows a route through open cells. NO ROUTE means obstacles block every route to G; try New map or edit some obstacles.

    
With zero delays, scheduled faults stop before the next move and live buttons freeze the current cell. Nonzero delays show an amber response phase before the red stop. Faults scheduled after arrival are not injected.

    
Reset, scenario selection, map selection, edits and loading a map start a fresh replay. This demo does not control hardware or demonstrate physical stopping performance.
